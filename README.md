# 快速访问固定项备份恢复工具

专门备份 / 恢复 Windows 资源管理器「快速访问」面板里**被固定（自定义）的文件夹**的小工具。
单文件 exe，双击即用，不需要安装 .NET 运行库，不写注册表。

> 本仓库只发布成品程序和说明文档，**不含源码**。

---

## 它解决什么问题

「快速访问」里固定着的文件夹，Windows 只把它们塞在一个二进制数据库里：

```
%APPDATA%\Microsoft\Windows\Recent\AutomaticDestinations\f01b4d95cf55d32a.automaticDestinations-ms
```

- 重装系统、换电脑、清理「最近使用」记录、某些优化软件清缓存，都可能把这份固定列表一起带走；
- 资源管理器本身**没有**导出 / 导入固定项的功能；
- 这个数据库整文件又是复合文档（OLE CFB）格式，直接文本搜索会拼出假路径。

这个工具就是干这件事：把当前固定项存成一份可回滚的快照，需要时一键还原。

注意：它只管**固定项**，不动「最近使用」记录，也不动开始菜单的固定项。

## 功能

**读取 / 展示**
- 直接向 Shell 的快速访问命名空间（`shell:::{679f85cb-0220-4080-b29b-5540cc05aab6}`）要实时清单，与资源管理器里看到的保持一致
- 列表列：序号 / 名称 / 类型 / 路径 / 状态 / 创建人
  - 状态「正常」= 文件夹在、记录有效
  - 状态「文件夹不存在」= 记录还在但文件夹已被删或移走（整行标红，不会藏起来不告诉你）
  - 创建人「系统」= 桌面/下载/文档/图片/音乐/视频这类系统默认项；「用户」= 自己固定的文件夹
- 双击任意一行可直接打开对应文件夹
- 一屏显示 15 行，超过 15 项才出现滚动条

**备份**
- 新建备份：数据库快照 + 人可读清单（pins.txt / pins.tsv / meta.txt）
- 「仅保留最近 N 份」自动清理旧备份（1–10 份，默认不勾，不勾就不删）
- 三种自动备份，可独立勾选：
  - 启动时自动备份（每次打开程序存一份）
  - 运行后自动备份（程序开满 N 分钟后存一份，1–180 分钟，默认 30）
  - 退出前自动备份（关闭程序前存一份）
- 备份列表的「备注」列写明每份备份怎么来的：手动 / 启动自动 / 定时自动 / 退出自动 / 命令行静默 / 还原前自动

**还原**
- 快照还原（推荐）：用选中的备份整体覆盖回去，最可靠，适用于同机、重装系统、固定项被误清空
- 按清单重新固定：按备份里的清单逐个重新固定（路径不存在的自动跳过）
- 还原前先自动备份（默认勾选），防手滑

**移除 / 添加固定项**
- 添加固定项：手选一个文件夹固定到快速访问
- 移除固定项（批量）：勾选一行或多行后批量取消固定；点列表「序号」标题可一键全选 / 全不选
- 取消固定走的是规范动词 `unpinfromhome`，并在重启一次资源管理器落盘后用实时清单复核，避免「提示成功但其实没生效」

**删除备份要过两道关**
- 必须勾选：一份都没勾就点删除，直接提示并停下，不会退而删掉某个「只是被选中」的行
- 第 1 步弹窗列出全部待删项确认 → 第 2 步随机出一道 20 以内加减法（答案不会是负数），答对才真正删除

## 下载与使用

**方式一：直接下载 exe（推荐先看这个）**

仓库的 Releases 页面里挂的就是 `快速访问固定项备份恢复工具.exe`，下载后双击即可。

**方式二：从仓库里的 Base64 文件还原（万一 Releases 还没挂）**

仓库根目录有一个 `快速访问固定项备份恢复工具.exe.base64.txt`，把它下载到本地，在它所在目录开一个 PowerShell 执行：

```powershell
$b = [Convert]::FromBase64String((Get-Content -Raw .\快速访问固定项备份恢复工具.exe.base64.txt))
[IO.File]::WriteAllBytes("$PWD\快速访问固定项备份恢复工具.exe", $b)
```

还原出来的 exe 与 Releases 里的完全一致（SHA-256 见 `SHA256.txt`）。

系统要求：Windows 10 / 11（64 位与 32 位均可）。程序没有数字签名，个别杀毒软件可能提示「未知发布者」，添加信任即可。

首次打开默认勾选「启动时自动备份」和「运行后自动备份（30 分钟）」，「仅保留最近 份」和「退出前自动备份」默认不勾。

### 备份存在哪

```
C:\Users\<你的用户名>\Documents\QuickAccess_Pins_Backup\QA_Pins_日期_时间\
  f01b4d95cf55d32a.automaticDestinations-ms   固定项数据库快照（还原用这个）
  pins.txt    人可读清单（名称 / 类型 / 标识 / 路径 / 是否存在）
  pins.tsv    机器可读清单（按清单重新固定用）
  meta.txt    备份时间、机器名、用户、项数、来源路径
```

### 命令行（给计划任务用）

```
快速访问固定项备份恢复工具.exe --backup   静默备份一份后退出，返回码 0 = 成功
快速访问固定项备份恢复工具.exe --list     把当前固定项打印成文字，供排查
```

`--backup` 不弹窗、不弹提示，适合挂到「任务计划程序」里定时跑；它不读界面里的备份目录设置，一律存到默认的 `Documents\QuickAccess_Pins_Backup\` 下面。

## 常见问题

**软件显示的固定项和资源管理器不一样？**
程序优先向 Shell 的快速访问命名空间取实时清单；只有在读取失败时才会退回解析数据库文件，这时清单可能包含已取消固定的历史记录（日志里会写明走了哪条路径）。

**还原后资源管理器没变化？**
还原会临时关闭并重启资源管理器（已打开的文件夹窗口会关掉），重启后列表才会刷新成还原后的样子。

**取消固定 / 添加固定一次没生效？**
程序会自动重启一次资源管理器再重试，并告诉你哪几项没成功。仍不行的话，可以直接在资源管理器里对着文件夹右键「固定到快速访问」/「从快速访问取消固定」。

**会不会碰到「最近使用」记录？**
不会。备份与还原只针对快速访问的固定项。
